질문 확인

자동으로 나눈 분류와 질문 ↔ 답변 연결을 확인하세요.

분류 확인 -

틀린 분류는 바로 바꾸면 돼요. 바꾼 분류는 그 줄 앞에 [분류]로 적혀 고정돼요.

답변 정리 선택 · 키워드 힌트용 -

위에 질문+답변 문서를 붙여 넣었다면 이미 연결돼 있어요. 답변만 따로 넣을 때는 Q1. 또는 1.처럼 질문 번호를 붙이거나, 질문과 답변을 함께 붙여 넣으세요. 면접 중에는 핵심 키워드만 힌트로 보여 줘요.

키워드 메모 선택 · 내가 정리한 키워드를 그대로 힌트로 자동

질문별로 정리한 키워드 메모를 통째로 붙여 넣으면, 답변 내용과 비교해 알맞은 질문에 자동으로 붙여요. 비워 두면 AI가 답변에서 핵심 키워드만 뽑아요 (AI가 없으면 자동 추출).
